# 🔐 AuthSystem – Next.js Frontend

A robust and user-friendly authentication system frontend built using Next.js. This app includes secure login, signup, and password reset features, ready to integrate with any backend API.

## 🚀 Features
- 🔐 Signup & Login
- 🔁 Forgot & Reset Password
- 🎨 Clean and responsive UI
- 🛡️ API-ready structure

## 🧰 Tech Stack
- Next.js
- React
- Tailwind CSS (if used)
- Axios (for API requests)
